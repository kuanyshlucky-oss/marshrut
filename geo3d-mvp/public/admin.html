Как загрузить слои из QGIS

Экспортируйте слой: Слой → Экспорт → Сохранить объекты как → GeoJSON, система координат EPSG:4326 (WGS84). Загрузите файл ниже. Если в файле есть ошибки, не загружается ничего — исправьте и повторите. MultiPolygon разбивается на отдельные объекты, внутренние контуры (дыры) игнорируются.

Очередь проверки

В модель попадают только скважины со статусом «проверена». Ошибки блокируют проверку, предупреждения требуют заметки геолога. Нажмите на строку, чтобы открыть карточку.

Отчёт по пилоту

Какие замечания встречаются чаще всего, насколько точно модель «угадывает» скважину по соседям (скважину убираем и предсказываем её) и сколько времени уходит на проверку. По этим цифрам геолог согласует пороги автопроверок.

Импорт скважин по слоям (CSV / Excel)

Для камеральщика: Шаблон Excel · Заполненный пример · Инструкция — вводят шапку и слои, лист «Экспорт» сохраняют как CSV UTF-8 и загружают ниже.
Одна строка = один слой. Строки с одним id объединяются в скважину; поля шапки (lng, lat, acc, z, date, depth, воды) повторяются в каждой строке и должны совпадать.
Обязательно: id, lng, lat, layer_from, layer_to, soil. Очень желательно: acc (A — RTK/тахеометр, B — GNSS, C — по схеме, D — неизвестно), z (абсолютная отметка устья), date, depth, doc (документ-источник), gw_stable / gw_first / gw_date.
Файл с ошибками в данных загружается, но скважины уходят в очередь с пометкой; отклоняется только файл, который нельзя прочитать (нет колонок, некорректный id). Старый упрощённый формат (b1–b4) тоже принимается и тоже попадает «на проверку».

Справочник грунтов

Название из журнала сопоставляется с классом модели по первому слову (основной грунт по ГОСТ 25100). Побеждает самое длинное совпадение начала. Справочник составляет и подписывает ваш геолог.

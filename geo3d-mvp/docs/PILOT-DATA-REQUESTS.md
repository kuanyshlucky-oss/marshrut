# Пилот «Юго-Восток»: запросы данных для ИЖС

Первый район пилота: **Юго-Восток (Караганда)**, приоритетный тип застройки: **ИЖС**. Границы района нужно зафиксировать до отправки запросов (см. шаг 0).

Названия органов и форматы выдачи уточняйте при подаче: структура ведомств и порядок получения данных меняются, а то, какие данные открыты, а какие выдаются по официальному запросу, я не проверял.

## Шаг 0. Зафиксировать район

1. Нарисуйте контур пилотной зоны в QGIS (WGS84, EPSG:4326) и сохраните как GeoJSON. Он станет «покрытием данных» (`coverage`) и областью сетки районов.
2. Добавьте запас 300 м: так граничные участки не окажутся «серыми».
3. Сетка для ИЖС: 250 м (по умолчанию в админке стоит 500 м, для пилота лучше 250).

## Приоритеты (что запрашивать первым)

Для ИЖС «красными» или «серыми» чаще всего делают участок данные из блоков 1, 3, 6, 7. Их и берём первыми.

| Приоритет | Блок паспорта | Что запрашиваем | Куда обращаться |
|---|---|---|---|
| **P1** | 1. Право и назначение | Список свободных участков и земли запаса в границах района: кадастровый номер, площадь, категория земель, целевое назначение, обременения, статус (свободен, торги, резерв, занят) | Отдел земельных отношений акимата; кадастровая служба (госорган, ведущий кадастр) |
| **P1** | 2. Градостроительство | Выкопировка из генплана и проекта детальной планировки (ПДП): зоны, красные линии, допустимая этажность для ИЖС | Управление архитектуры и градостроительства акимата |
| **P1** | 3. Инженерные сети | Схемы существующих и планируемых сетей (вода, канализация, электричество, газ): трассы, диаметры, **свободная мощность**, точки подключения | Водоканал, электросети, газоснабжающая организация, при необходимости теплосети |
| **P1** | 6. Опасные процессы | Границы подрабатываемых территорий (шахты), зон подтопления, отвалов, загрязнения | Недропользователь / бывший владелец шахт, управление по чрезвычайным ситуациям, акимат |
| **P1** | 7. Охранные и санитарные зоны | Охранные зоны ЛЭП, газопроводов, водоводов; санитарно-защитные зоны предприятий, кладбищ, полигонов | Владельцы сетей, акимат, санитарная служба |
| **P2** | 4. Рельеф | Топоматериалы масштаба 1:500–1:2000 или ваша дроновая съёмка с ЦМР; уклоны по участкам | Ваша съёмка, управление архитектуры |
| **P2** | 5. Грунты | Архив изысканий по району: журналы скважин, отчёты, УГВ | Ваш архив, фонд инженерных изысканий, проектные организации |
| **P3** | прочее | Транспорт и подъезды, соцобъекты рядом, стоимость подключения | Акимат, открытые данные, 2ГИС/OSM |

## Какой формат просить и что мы с ним делаем

| Данные | Лучший формат | Куда кладём в системе |
|---|---|---|
| Участки | GeoJSON/Shapefile/KML, WGS84 (или МСК с указанием кода) | Админка → «Слои участков» → участки (`parcels`) |
| Зоны ограничений | то же, полигоны | `constraints` (kind: protection, sanitary, undermined, flood, slag, contamination) |
| Сети | линии GeoJSON/Shapefile + таблица мощностей | `utilities` (kind, `capacity_free`, `owner`) |
| Покрытие | ваш контур района с датой актуальности | `coverage` для слоёв hazards, protection, utilities |
| Скважины | CSV по шаблону оцифровки | Админка → скважины (шаблон из `public/templates/`) |
| Генплан, ПДП | PDF/растр | Справочно; зону переносим вручную в `parcels.zone` и `max_floors` |

Если данные приходят в местной системе координат, просите указать её код: без него наложить слои нельзя.

- [ ] Запросы владельцам сетей: вода, канализация, электричество, газ (P1, блок 3).

Обязательно уточните в запросе **условия использования**: можно ли показывать данные публично на сайте и использовать в платном сервисе. От этого зависит, какие слои вы сможете показывать людям, а какие только использовать для внутреннего расчёта.

## Что делать, если данных нет или их не дают

- **Нет участков:** покажем сетку районов (светофор территории) и отметим «участки не размежёваны, смотрите кадастровую карту».
- **Нет данных по сетям:** блок серый («данные не загружены»), а не зелёный; это уже заложено в системе.
- **Нет карты подработки:** блок «опасные процессы» остаётся серым. Не подменяйте его «зелёным»: для Караганды это существенный риск.
- **Данные дают только на бумаге/PDF:** оцифровывает камеральщик; отнесите это на пилотный бюджет времени.

## Критерии, что пилот данных собран

- По району есть контур покрытия и хотя бы три слоя с датой: участки, сети, зоны.
- Не менее 80 % участков получили светофор, отличный от серого.
- Для 10 контрольных участков результат светофора совпал с мнением вашего инженера (или расхождения объяснены).
- Понятно, какие данные можно показывать публично.

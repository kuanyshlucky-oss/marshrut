# Маркетолог JetisHUB (бот для рилсов)

Окно чата на вашем компьютере. Вы выбираете тип рилса, заполняете короткую форму, бот выдаёт готовые сценарии для Instagram: хуки, сценарий по секундам, подпись и хэштеги, план проверки (A/B).

- **Таргет-рилсы**: реклама, которая приводит заявки в WhatsApp.
- **Информационные**: полезный контент про магистратуру (рубрики, темы на месяц).
- **Свободный чат**: правки, перевод на казахский, идеи постов.
- Галочка **«Добавить промты для AI-генератора видео»**: к каждому кадру бот допишет английский промт для Runway / Pika / Higgsfield и др.

Правила бота (не обещает грант и баллы, не выдумывает цифры, без чужих кадров в рекламе) лежат в [jetishub-marketing-bot-prompts.md](../jetishub-marketing-bot-prompts.md). Правите этот файл, перезапускаете бота, и бот работает по новым правилам.

## Запуск (один раз настроить, потом двойной клик)

1. **Получите ключ API.** Откройте console.anthropic.com → API keys → Create key. Ключ выглядит как `sk-ant-...`. Пополните баланс на несколько долларов (см. «Сколько стоит»).
2. **Сохраните ключ в файл.** В папке `marketing-bot` скопируйте `.env.example` в `.env`, откройте `.env` блокнотом и допишите ключ после знака `=`:
   ```
   ANTHROPIC_API_KEY=sk-ant-ваш-ключ
   ```
   Файл `.env` никуда не отправляется (он в `.gitignore`). Никому не показывайте ключ и не вставляйте его в чат.
3. **Запустите.** Двойной клик по `start.bat`. Откроется страница http://localhost:3010. Окно с чёрным фоном не закрывайте, пока работаете с ботом.

Нужен Node.js 22 или новее (у вас он уже стоит). Зависимости (`node_modules`) уже установлены; если папку перенесёте на другой компьютер, выполните там `npm install`.

## Как пользоваться

1. Выберите вкладку: «Таргет-рилсы» или «Информационные».
2. Заполните форму (угол, оффер, номер WhatsApp, язык и т. д.) и нажмите **«Сгенерировать»**.
3. Через несколько секунд бот напишет сценарии. Просите правки строкой внизу: «сделай хук короче», «переведи на казахский», «добавь про рассрочку».
4. **«Копировать»** под ответом копирует весь текст. **«Новый чат»** начинает с чистого листа. **«Стоп»** прерывает ответ (токены больше не тратятся).

## Сколько стоит

Работает на модели Claude Opus 5.5 ($4 за миллион входных и $20 за миллион выходных токенов). Один запрос на 3 сценария это в среднем около 10 центов. Дешевле: в файле `.env` добавьте строку `MARKETING_BOT_MODEL=claude-sonnet-5-5` (примерно вдвое дешевле, качество текста чуть проще). Системные правила кешируются между сообщениями, так что правки в том же чате стоят меньше.

## Безопасность

- Бот слушает только `localhost`: из интернета и из вашей сети к нему не подключиться, ваш ключ чужие не потратят.
- Ключ читается из `.env` сервером и в браузер не попадает.
- Не публикуйте эту папку вместе с файлом `.env`.

## Если что-то не так

| Что вижу | Что делать |
|---|---|
| «Ключ API не найден» | Нет файла `.env` или в нём пусто после `=`. Заполните и перезапустите `start.bat`. |
| «Ключ API не принят» | Ключ введён с ошибкой или отозван. Создайте новый на console.anthropic.com. |
| «Слишком много запросов» | Подождите минуту. |
| Страница не открывается | Окно `start.bat` закрыто или порт 3010 занят. Задайте другой порт: в `.env` строка `PORT=3020`. |
| Ответ обрывается | Напишите «продолжи». |

## Из чего состоит

- `server.js`: локальный сервер, ходит в Claude API и передаёт ответ в окно по частям.
- `public/index.html`: окно чата.
- `build-prompts.js`: при каждом запуске собирает `prompts.js` из `../jetishub-marketing-bot-prompts.md`.
- `start.bat`: запуск двойным кликом.

## Важно: файл с промтами не в репозитории

Репозиторий публичный, поэтому файл `jetishub-marketing-bot-prompts.md` (в нём цены, формулировка гарантии и маркетинговые правила) и собранный из него `prompts.js` в GitHub **не отправляются**. Файл должен лежать рядом с папкой `marketing-bot`: `start.bat` соберёт из него промты при запуске. На другом компьютере скопируйте этот файл вручную.

# 3D-карта Караганды для застройщиков — идея и roadmap

Дата записи: 2026-11-24

## 1. Идея

Веб-сервис на базе геодезической компании в Караганде. Человек или компания, которые хотят строить, заходят на сайт, выбирают участок на 3D-карте, оплачивают отчёт, видят:

- рельеф и местность участка в 3D;
- границы, соседние участки, дороги, коммуникации (где есть данные);
- грунт под участком в 3D: слои, глубина залегания, уровень грунтовых вод (по нашим скважинам и шурфам);
- скачивают отчёт (PDF) и/или файлы (DXF, GeoTIFF, OBJ/GLB).

**Что ценного.** Реальный актив здесь — не 3D-карта (её можно купить или собрать из открытых данных), а **собственные данные по грунту и съёмки**, которых нет у других. Продукт должен держаться на них.

## 2. Честная оценка идеи

Идея не плохая, но в виде «вся Караганда в 3D с грунтом» — слишком большая и дорогая как первый шаг.

Основные риски:

1. **Данные по грунту точечные.** Скважины и шурфы есть только там, где вы работали. Между ними — интерполяция. Нельзя выдавать это за точный прогноз.
2. **Юридическая ответственность.** Модель грунта — ориентировочная. Для проектирования по закону нужны инженерные изыскания (ИГИ) на конкретном участке. Это нужно писать прямо в отчёте. Это же и плюс: сервис приводит клиентов на ваши платные изыскания.
3. **Доступ к геоданным в РК.** Есть ограничения на топографо-геодезические материалы и кадастр; нужна лицензия на геодезическую деятельность (у вас, судя по всему, есть) и проверка, какие данные можно публиковать онлайн. **Проверить с юристом.**
4. **Вся карта сразу = годы работы.** Нужно начать с узкой версии и расти от спроса.
5. **Мало платящих клиентов?** Нужно проверить спрос до разработки: сколько застройщиков/частников реально заплатят за такой отчёт и сколько.

## 3. Как сделать удобно (UX)

- Один экран: карта → клик по участку (или поиск по кадастровому номеру/адресу) → превью → «Купить отчёт».
- Бесплатно показываем: 2D/3D рельеф, границы, базовые данные. Платно: грунт, разрезы, отчёт, файлы.
- Переключатель слоёв: рельеф / спутник / кадастр / грунт / скважины.
- Вертикальный разрез: пользователь проводит линию — видит слои грунта по глубине.
- Слайдер глубины: «покажи грунт на глубине 3 м».
- Мобильная версия (много людей откроют с телефона).
- Оплата: Kaspi Pay / Halyk epay / Freedom Pay (уточнить, что подключается проще для ИП/ТОО).
- Кнопка «Заказать изыскания на этом участке» — основной путь монетизации.
- Языки: RU + KZ.

## 4. Данные: что нужно

| Данные | Источник | Заметки |
|---|---|---|
| Базовый рельеф | Copernicus DEM 30 м (бесплатно) | Только для старта, точность низкая |
| Точный рельеф и 3D-модель местности | **Ваша съёмка**: дрон с RTK + фотограмметрия или лидар | Основной актив по геометрии |
| Кадастр, границы участков | Государственные источники (НАО «Правительство для граждан», публичная кадастровая карта) | Проверить условия использования |
| Здания, дороги | OpenStreetMap + ваша съёмка | OSM для старта |
| Спутник | Sentinel-2 (бесплатно), коммерческие снимки (платно) | |
| **Скважины/шурфы** | **Ваш архив изысканий**: координаты, отметки, описание слоёв, УГВ, лабораторные данные | Самое ценное; нужно оцифровать |
| Коммуникации | Заказчики/эксплуатанты, ваши съёмки | Чувствительные данные, юридически сложно |

**Первое действие:** собрать ваш архив изысканий за все годы и посчитать — сколько скважин, где, в каком формате (бумага/PDF/Excel/CAD). От этого зависит весь проект.

## 5. Инструменты

**Сбор и обработка**
- Дрон с RTK (например DJI Mavic 3 Enterprise для фотограмметрии; Matrice + лидар для высокой точности) + GNSS-приёмники для опорных точек.
- Обработка: WebODM (бесплатно), Agisoft Metashape или Pix4D (платно).
- ГИС: QGIS (бесплатно), PostGIS для хранения.

**3D грунта**
- Оцифровка скважин в таблицу: `borehole_id, x, y, z, слой, от, до, тип грунта, УГВ`.
- Интерполяция слоёв: Python (PyKrige, GemPy) или простая схема «слой по ближайшим скважинам» на первом этапе.
- Сильный платный вариант — Leapfrog / Surpac / Civil 3D (Surfaces), если есть бюджет.

**Веб**
- 3D-карта: CesiumJS (терраины, 3D Tiles) или MapLibre GL + deck.gl (легче и быстрее). Для облаков точек — Potree.
- Бэкенд: PostgreSQL + PostGIS, FastAPI или Node.js; хранение тайлов и файлов — S3-совместимое хранилище.
- Тайлы/слои: GeoServer или pg_tileserv/Martin; 3D Tiles через Cesium ion или собственный генератор.
- Оплата и выдача отчётов: платёжный провайдер + генерация PDF (WeasyPrint/Puppeteer).
- Хостинг: VPS в РК/ближнем зарубежье + CDN (проверить требования по хранению данных).

## 6. Roadmap

Оценки ориентировочные для небольшой команды (1 разработчик + 1–2 геодезиста/камеральщика). Сроки зависят от состояния вашего архива и числа людей.

### Этап 0 — Проверка идеи (2–4 недели)
- Разговор с 10–15 потенциальными клиентами (застройщики, частники, архитекторы): что хотят, за что заплатят, сколько.
- Консультация юриста: какие данные можно публиковать/продавать.
- Инвентаризация архива скважин и съёмок.
- **Критерий перехода:** минимум несколько людей говорят «да, заплачу за это» и данных достаточно для пилотной зоны.

### Этап 1 — Пилот на одной зоне (6–10 недель)
- Выбрать 1–2 района с самым большим числом ваших скважин и самым горячим спросом на землю.
- Оцифровать скважины этих районов в PostGIS.
- Облёт дроном зоны, 3D-модель рельефа и построек.
- Простая 3D-карта (MapLibre/Cesium) + клик по точке → столбик грунта по ближайшим скважинам.
- Ручная продажа: отчёт PDF вручную, оплата переводом. Цель — первые деньги и обратная связь.

### Этап 2 — MVP с оплатой (2–3 месяца)
- Регистрация/вход, выбор участка, корзина, онлайн-оплата.
- Автогенерация отчёта (PDF) по участку: карта, разрез, таблица слоёв, дисклеймер.
- Интерполяция грунта между скважинами + отметка «достоверность» (расстояние до ближайшей скважины).
- Кнопка «Заказать изыскания».
- Админка: загрузка новых скважин и съёмок.

### Этап 3 — Расширение покрытия (6–12 месяцев, параллельно с работой компании)
- Каждый новый заказ изысканий → данные автоматически попадают в базу (скважины, съёмка). Это главное: карта растёт «бесплатно» из основной работы.
- Дополнительные облёты районов по плану, начиная с самых востребованных.
- Слои: коммуникации (где можно), зоны ограничений, уклоны, затопляемость.
- Подписка для застройщиков (доступ к нескольким участкам/месяц, API).

### Этап 4 — Полная версия города (1,5–3 года)
- Покрытие основных городских районов съёмкой.
- Полноценная 3D-модель грунта по зонам с достаточной плотностью скважин; в остальных — пометка «данных недостаточно».
- Партнёрства: акимат, архитекторы, банки/застройщики, оценщики.
- Продажа данных/API корпоративным клиентам.

## 7. Сколько времени всего

| Результат | Срок |
|---|---|
| Проверка спроса + юридическая часть | 1 месяц |
| Пилот (1–2 района, ручные отчёты) | 2–3 месяца |
| Работающий сайт: зашёл → оплатил → увидел участок и грунт → скачал отчёт | **4–6 месяцев** от старта |
| Покрытие значительной части города | 1–2 года |
| «Вся Караганда в 3D с грунтом» | 2–3+ года, зависит от числа скважин |

Главный вывод: **сайт с оплатой можно сделать за 4–6 месяцев**, но «полная карта грунта» растёт со временем вместе с вашими изысканиями. Не ждите полного покрытия — запускайте на тех районах, где данные уже есть.

## 8. Ориентировочные затраты (порядок величины, уточнить)

- Разработка веба (MVP): зависит от того, делаете сами/нанимаете; от нескольких миллионов до десятка миллионов тенге при найме.
- Дрон RTK + ПО: если нет — от ~2–5 млн ₸ для базового комплекта; лидар — значительно дороже.
- Хостинг и хранение: десятки тысяч ₸ в месяц на старте, растёт с объёмом тайлов.
- Оцифровка архива: самая трудоёмкая статья — человеко-часы камеральщиков.

## 9. Следующие шаги

1. Посчитать архив: сколько скважин, где, в каком виде.
2. Выбрать пилотный район.
3. Опросить 10 потенциальных клиентов.
4. Проконсультироваться с юристом по данным и ответственности.
5. Сделать прототип на QGIS + MapLibre за 2–3 недели и показать клиентам.
